Guía Institucional: Imágenes Docker

1. ¿Qué es una imagen base en SOLV?

Es el entorno preconfigurado con el sistema operativo, herramientas y compiladores (Python, Node, GCC, OpenJDK, etc.) donde el estudiante programará sus ejercicios dentro del editor web.

2. Regla de Reproducibilidad (Sin :latest)

Por seguridad institucional y acreditación académica, no está permitido el tag :latest. Las plantillas deben usar versiones fijas inmutables (ej: node:20-bookworm-slim o python:3.12-slim-bookworm) para garantizar que las prácticas evalúen exactamente igual hoy y en años futuros.

3. Optimización de Almacenamiento

Prefiera siempre imágenes con sufijo -slim o -alpine. Evite imágenes que incluyan suites gráficas de escritorio innecesarias, ya que saturan la memoria y el almacenamiento del host físico.

4. Imágenes Propias y Multi-Arquitectura

El servidor SOLV opera en procesadores x86_64 (amd64). Si compila una imagen personalizada desde una Mac Apple Silicon (ARM64), use buildx para compilar la variante adecuada antes de subirla:

docker buildx build --platform linux/amd64 -t mi-organizacion/mi-lab:1.0 --push .
