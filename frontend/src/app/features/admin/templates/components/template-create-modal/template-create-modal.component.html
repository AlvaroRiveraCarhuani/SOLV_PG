Contrato de ejecución del Juez Virtual

Comando de Ejecución (entrypoint): Define la línea de compilación y ejecución que se correrá en el sandbox efímero aislado sin red.

Tiempo límite (timeout_ms): Control estricto del cgroup de CPU. Si el proceso excede este límite (1.000 a 30.000 ms), el sandbox lo termina y emite veredicto TLE.

Entrada estándar (sample_input): Flujo de entrada stdin opcional inyectado automáticamente en la prueba preliminar de arranque.

Glosario de veredictos (en tiempo de ejecución)
  • AC: AC (Accepted): Código 0 y salida idéntica al caso de prueba.
  • WA: WA (Wrong Answer): Salida diferente a la esperada por el ejercicio.
  • TLE: TLE (Time Limit Exceeded): Ejecución interrumpida al exceder el timeout configurado.
  • RE: RE (Runtime Error): Terminación con código de salida distinto de cero o excepción no capturada.
  • AST_BLOCKED: AST_BLOCKED: Bloqueo estático por análisis de sintaxis prohibida.
