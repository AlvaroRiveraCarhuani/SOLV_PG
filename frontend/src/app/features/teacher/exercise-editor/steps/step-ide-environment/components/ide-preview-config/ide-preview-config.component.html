Ejecución de la aplicación

SpeedGrader abre la aplicación en una pestaña nueva para que revises el comportamiento real de la entrega. El contenedor se apaga solo cuando deja de tener actividad.

Se ejecuta dentro de una copia inmutable del snapshot, nunca en el workspace del alumno.
Puerto TCP donde escucha la app dentro del contenedor. Si se omite, se usa 3000.

Sin comando de arranque no se puede probar la aplicación: el sistema no lo adivina a partir del proyecto.
